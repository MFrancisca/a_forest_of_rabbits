# Blog ("journal" app) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a blog at `/blog/` (new `journal` app) with curated tags, optional links to projects, an "Updates on this project" list on project pages, and a "Latest pigment notes" sidebar on the pigment pages.

**Architecture:** Wagtail page models (`BlogIndexPage`, `BlogPostPage`) plus a `Tag` snippet in a new `journal` app. Post bodies reuse the `blog` app's StreamField blocks. The pigment sidebar is one inclusion tag used by both pigment templates. Post images are filed into a single "Blog" collection on save.

**Tech Stack:** Django 6.1, Wagtail 8.x, pytest + pytest-django + wagtail_factories, Tailwind v4 standalone, Alpine 3 (already loaded in `base.html`), Playwright + axe for a11y tests.

**Spec:** `docs/superpowers/specs/2026-11-12-blog-design.md`

## Global Constraints

- App label `journal`; the existing `blog` app is not renamed.
- Public URL `/blog/`, nav label "Blog", 404 section item "post".
- Tags are a curated snippet (`journal.Tag`), shown as checkboxes; seeded with name `Pigments`, slug `pigments`; constant `PIGMENTS_TAG_SLUG = 'pigments'`.
- Images are never deleted, only moved between collections. All post images go to one top-level collection `BLOG_COLLECTION_NAME = 'Blog'`; only images in the root collection move.
- Only live (published) posts and projects appear on public pages.
- Index pagination: 10 per page. Sidebar: 3 newest Pigments posts.
- `summary` max 300 chars, optional; fallback ~300 chars cut at a word, "…" only when cut.
- `localStorage` key `pigmentNotesHidden`, every access in try/catch, default shown.
- No RSS, no free-typed tags, no pigment/manuscript links.
- Commit only when the user asks (CLAUDE.md overrides the per-task "Commit" steps: stage the files and leave the commit until the user says so, or batch them per the user's instruction). Never stage `CLAUDE.md` or `scripts/codex-review.sh`.
- Files created in the `web` container are root-owned: `chown -R 1000:1000 journal/migrations` (and any other generated dir) inside the container.

## Branching

`feat/manuscript-illuminations` (PR #34) also edits `pigments/templates/pigments/pigment_detail.html`. If #34 is merged when work starts, branch `feat/blog` from `origin/master`; otherwise branch from `feat/manuscript-illuminations` and open the PR against it.

## Review Focus

- A post whose body starts with an image or carousel block, or a rich-text block that is only an embedded image: `display_summary` skips blocks with no text and uses the first one that has text.
- `?tag=` with an unknown slug, or `?page=abc` / `?page=999`: index returns 200 (empty list with a message / last page), never 404 or 500.
- A post linked to a project that is later unpublished: the post page omits that project; the project's draft isn't linked.
- The Pigments tag renamed in the admin: sidebar still works (slug unchanged); tag deleted: sidebar disappears without errors.
- HTMX filter requests on `/pigments/` (`HX-Request`): the partial response must not contain the sidebar, and the full page must keep it after filtering.
