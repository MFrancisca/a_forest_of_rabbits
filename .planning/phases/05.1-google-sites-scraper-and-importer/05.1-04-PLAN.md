<task type="auto">
  <name>Task 1: Rebuild Docker image and run the scraper command</name>
  <files></files>
  <action>
    1. Rebuild the Docker image to install Playwright/Chromium:
       ```bash
       docker compose build
       ```
       This may take several minutes due to the ~130 MB Chromium binary download.

    2. Run the scraper in dry-run mode first to preview output without touching the database:
       ```bash
       docker compose exec web python manage.py scrape_google_sites --dry-run
       ```
       Verify: 12 lines of `[dry-run] Would create/update...` output appears, no errors.

    3. Run the full scraper against the live site:
       ```bash
       docker compose exec web python manage.py scrape_google_sites
       ```
       Expected output pattern:
       ```
       → Scraping: https://www.unanuovasperanza.art/home
       ✓ Updated: AboutPage
       → Scraping: https://www.unanuovasperanza.art/projects/scrolls/qc-sonja-iii
       ✓ Created: [title]   (or ⏭ Skipped if manually migrated page slug matches)
       ...
       ─────────────────────────────────
       Scrape complete
       Created:  N
       Skipped:  M (existing)
       Failed:   0
       ─────────────────────────────────
       ```
       Failed: 0 is the pass condition. If any failures occur, note the error message and attempt to fix before proceeding.

    4. If any page fails: inspect the error, adjust the `extract_body_html` selector logic if needed (Google Sites CSS classes may differ from inspected values), re-run.
  </action>
  <verify>
    <automated>docker compose exec web python manage.py scrape_google_sites --dry-run 2>&1 | grep -c "Would"</automated>
  </verify>
  <done>docker compose build completes; dry-run shows 12 Would-lines; full run prints "Failed:   0" in summary block</done>
</task>
