CRITICAL INHERITANCE RULES:
- Any model with InlinePanel children MUST inherit ClusterableModel
- Children use ParentalKey (NOT ForeignKey) to their parent
- Children should also inherit Orderable for drag-to-reorder in admin
- Formula is TWO levels deep (Pigment → Formula → FormulaPart) so Formula needs BOTH ClusterableModel AND Orderable
- django.contrib.admin is EXCLUDED — all admin surface is Wagtail Snippets only

Import pattern:
  from django.db import models
  from modelcluster.fields import ParentalKey
  from modelcluster.models import ClusterableModel
  from wagtail.models import Orderable
  from wagtail.snippets.models import register_snippet
  from wagtail.admin.panels import FieldPanel, InlinePanel
  from wagtail.images.models import Image  # for PigmentImage FK

Models to create (in dependency order):

1. ColorFamily — @register_snippet, name (CharField unique), ordering=['name']
2. PigmentFamily — @register_snippet, name (CharField unique), ordering=['name']
3. Country — @register_snippet, name (CharField unique), ordering=['name']
4. Brand — @register_snippet, name (CharField unique), ordering=['name']
5. Paint — @register_snippet, brand (FK to Brand PROTECT), name (CharField), hex_color (CharField max_length=7, blank=True, help_text='CSS hex e.g. #A3B2C1')
6. Manuscript — @register_snippet, name (CharField), country (FK to Country PROTECT null blank), date_start (IntegerField null blank, help_text='Year CE'), date_end (IntegerField null blank), notes (TextField blank)
7. Pigment — @register_snippet + ClusterableModel, name (CharField), color_family (FK to ColorFamily PROTECT null blank), pigment_family (FK to PigmentFamily PROTECT null blank), description (TextField blank). panels include InlinePanel('formulas'), InlinePanel('manuscript_links'), InlinePanel('images')
8. Formula — ClusterableModel + Orderable, pigment (ParentalKey to Pigment related_name='formulas' CASCADE), brand (FK to Brand PROTECT), notes (TextField blank). panels include InlinePanel('parts')
9. FormulaPart — Orderable, formula (ParentalKey to Formula related_name='parts' CASCADE), paint (FK to Paint PROTECT), parts (DecimalField max_digits=5 decimal_places=2)
10. PigmentManuscript — Orderable, pigment (ParentalKey to Pigment related_name='manuscript_links' CASCADE), manuscript (FK to Manuscript PROTECT), page_reference (CharField max_length=100 blank), notes (TextField blank)
11. PigmentImage — Orderable, pigment (ParentalKey to Pigment related_name='images' CASCADE), image (FK to wagtailimages Image on_delete=SET_NULL null=True blank=True related_name='+'), caption (CharField max_length=255 blank), alt_text (CharField max_length=255 blank)

For wagtail_hooks.py — use SnippetViewSet to customise list views (columns, search):
  from wagtail.snippets.views.snippets import SnippetViewSet
  from wagtail.snippets.models import register_snippet

Wagtail 7.0 uses SnippetViewSet + register_snippet via hooks. @register_snippet decorator on the model is sufficient for basic admin — wagtail_hooks.py is optional for Phase 1 but create a minimal one to confirm hooks are wired.
