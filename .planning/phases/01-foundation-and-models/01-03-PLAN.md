  <action>
Build the production Tailwind CSS file locally and commit it to the repo. This implements the locked decision: "Tailwind prod: commit built output.css to repo — no Node in Docker image, simpler Dockerfile."

The Dockerfile has NO Node or build step. Docker serves output.css via whitenoise/collectstatic.

**Step 1 — Build output.css using the Tailwind CLI:**

Option A (npx, no global install needed):
```bash
npx tailwindcss -i core/static/css/main.css \
  -o core/static/css/output.css \
  --content "core/templates/**/*.html" \
  --minify
```

Option B (if Tailwind CLI is installed globally: `npm install -g tailwindcss`):
```bash
tailwindcss -i core/static/css/main.css \
  -o core/static/css/output.css \
  --content "core/templates/**/*.html" \
  --minify
```

Option C (if no Node available locally): Use the standalone Tailwind CLI binary.
Download from https://github.com/tailwindlabs/tailwindcss/releases/latest —
pick the linux-x64 binary, make it executable, run it with the same flags as Option A.
```bash
curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-linux-x64
chmod +x tailwindcss-linux-x64
./tailwindcss-linux-x64 -i core/static/css/main.css \
  -o core/static/css/output.css \
  --content "core/templates/**/*.html" \
  --minify
```
