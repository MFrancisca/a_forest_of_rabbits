  <what-to-do>
Follow `docs/migration-guide.md` to migrate all Google Sites articles into Wagtail. The guide is step-by-step — work through it in order.

**Before starting:**
1. Start the dev server: `docker compose up`
2. Confirm Projects index exists: visit http://localhost:8000/projects/ — must return 200. If 404, run: `docker compose exec web python manage.py create_site_skeleton`
3. Open the live Google Sites (www.unanuovasperanza.art) in one browser tab and the Wagtail admin (/cms/) in another

**For each article (repeat for every article in Calligraphy & Illumination, Clothing, and Armor):**
1. Download all images from the Google Sites article (right-click > Save image as)
2. Upload images to Wagtail image library: /cms/ > Images > Add an image
3. Create the ProjectPage: /cms/ > Pages > Root > Projects > "+ Add child page" > Project page
4. Fill in: Title, Date, Category, Excerpt — leave Cover Image BLANK
5. Add body text; insert images inline using the body editor image toolbar button
6. Click Publish (NOT Save draft)
7. Visit the article URL in the browser — confirm all images display
8. Tick the row in `docs/migration-checklist.md`, fill in the Wagtail URL

**After all articles are complete:**
- Commit the completed checklist: `git add docs/migration-checklist.md && git commit -m "docs(05): complete content migration checklist"`

**Reference:** `docs/migration-guide.md` has the full step-by-step instructions including the image insertion sub-steps (the trickiest part).
