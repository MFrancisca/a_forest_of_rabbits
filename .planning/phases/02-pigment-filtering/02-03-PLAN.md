<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Browser verification of filtering UX</name>
  <action>Human opens the browser and runs through 9 verification checks for the filterable pigment list at http://localhost:8000/pigments/</action>
  <what-built>
    Complete HTMX-powered filterable pigment list at /pigments/ with:
    - Five filter dropdowns (Color Family, Pigment Family, Country, Manuscript, Time Period)
    - Active pills row with x buttons and "Clear all" link
    - Consecutive century pill merge
    - Result count display
    - HTMX partial swaps (no full page reload on filter change)
    - Bookmarkable/shareable URLs with filter state in query params
    - Browser back button support via HX-History-Restore-Request handling
    - Empty state message when no results match
  </what-built>
  <how-to-verify>
    Open http://localhost:8000/pigments/ in your browser. Run through each check:

    1. BASIC LOAD
       - Page loads showing a list of pigments
       - Five filter dropdowns are visible in a horizontal bar above the list
       - Result count shows "X pigments" (unfiltered)
       - Active pills row is NOT visible (no filters selected yet)

    2. SINGLE FILTER — COLOR FAMILY
       - Click the "Color Family" dropdown → panel opens with options
       - Select "Blue" → list updates WITHOUT a full page reload (no flash)
       - URL in browser bar changes to include ?color=... (or equivalent param)
       - Result count changes to "X of Y pigments"
       - An active pill appears below the dropdowns: "Blue" with an x button

    3. MULTI-SELECT WITHIN DIMENSION
       - With Blue still selected, also select "Red" in the same dropdown
       - List updates to show pigments from EITHER Blue OR Red
       - Two pills appear: "Blue" and "Red"

    4. AND ACROSS DIMENSIONS
       - Keep "Blue" selected, then select "Italy" in the Country dropdown
       - List should show only Blue pigments from Italy (not all Blue + not all Italy)
       - Two pills from different dimensions

    5. PILL REMOVAL
       - Click x on the "Blue" pill → Blue filter removed, list updates with only Italy filter active
       - Click "Clear all" link → all filters removed, full list restored, pills row disappears

    6. CENTURY FILTER
       - Open the "Time Period" dropdown
       - Select two adjacent centuries (e.g. 9th and 10th)
       - Verify: a SINGLE merged pill appears (e.g. "9th-10th centuries") instead of two separate pills

    7. EMPTY STATE
       - Apply a filter combination that produces no results (e.g. select a country that has no pigments)
       - Verify: "No pigments match these filters" message appears (not a blank list)
       - "Clear filters" link is visible and clickable

    8. BOOKMARKABLE URL
       - Apply one or more filters
       - Copy the URL from the browser bar
       - Open a new tab and paste the URL
       - Verify: same filtered results appear (filter state reconstructed from URL params)

    9. BROWSER BACK BUTTON
       - Start on /pigments/ unfiltered
       - Apply a filter (list updates, URL changes)
       - Navigate to a different page (e.g. /cms/)
       - Press the browser back button
       - Verify: /pigments/ loads as a FULL PAGE (not broken partial HTML) with the previously active filter shown

  </how-to-verify>
